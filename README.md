# FoodBridge 🍲

> A responsive ASP.NET Core MVC web application developed to streamline community food management, donations, and  distribution.

---

## 📌 Overview
FoodBridge is a database-driven web platform designed to bridge the gap between food donors and community distribution centers. The system provides structured workflows for tracking available supplies, managing requests, and maintaining inventory records efficiently.

## ✨ Key Features
- **MVC Architecture:** Structured separation of concerns using Model-View-Controller design patterns.
- **Data Management & Persistence:** Built with Entity Framework Core to manage data entities, relationships, and queries.
- **Dynamic Views:** Responsive Razor views styled with Bootstrap for accessible desktop and mobile navigation.
- **CRUD Operations:** Complete Create, Read, Update, and Delete workflows for food items, listings, and donor records.

## 🛠️ Tech Stack
- **Framework:** ASP.NET Core MVC (.NET 8 / C#)
- **Data Layer:** Entity Framework Core / SQL Server
- **Frontend:** Razor Views (HTML5/CSS3), JavaScript, Bootstrap
- **Tools:** Visual Studio, Git
